      Full P & K + 1/3rd Nitrogen

      Apply 100% DAP, 100% MOP, and 1/3rd Urea directly into root furrow 5cm below root zone.

      📦 References

      • Dataset: New Plant Diseases Dataset — 87,900 images, 38 classes (Kaggle)
      • Disease Model: Custom Multi-Modal Dual-Head Deep CNN (ResNet-18 + Tabular MLP Fusion)
      • Yield Model: Microclimate-conditioned regression network based on soil NPK and meteorological telemetry
      • Weather: Open-Meteo API (free, no API key)
      • Framework: PyTorch · FastAPI · Vanilla JS · SQLAlchemy Async
